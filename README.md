# ToDo-List

A small, web-based To-Do List app built with plain HTML, CSS, and JavaScript.

### Features

- Add and remove tasks
- Mark tasks as completed
- Double-click a task to edit it inline
- Drag and drop tasks to reorder them
- Tasks persist in localStorage across page reloads
- Neon-themed UI with custom-styled checkboxes
- Counters for total and completed tasks

### Installation / Run Locally

1. Clone or download the repository.
2. Open `index.html` in your browser.

No build step or server is required.

### Usage

- Type a task into the input field and click "Add Task" or tap the Enter key.
- Click the checkbox beside a task to mark it as completed.
- Double-click a task's text to edit it.
- Drag tasks to reorder them.
- Use the delete button next to a task to remove it.
